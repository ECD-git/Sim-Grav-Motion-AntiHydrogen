# Sim-Grav-Motion-AntiHydrogen
All code written for the Semester 8 MPhys project "Simulating the Gravitational Motion of Antimatter Hydrogen Atoms", the report for which can be found in this repo.

# Features
- Randomly distributes velocities subject to a distribution (eg, Maxwell Boltzmann dsitribution or a uniform sphere).
- Randomly perturbs N free particles with a random "kick" subject to a random walk simulation, at at interval determined by a mean-free-path calculation.
- Checks the energy of particles against an escape threshold, records escape times, and also the velocity distribution at regular intervals.
- Generates various histograms based on simulation data.
